# HostDocs MCP Server

This is a first-party Model Context Protocol (MCP) server for the HostDocs workspace.

## Features

- stdio transport for local editor and agent integration
- `echo` tool for testing connectivity
- `read-repo-status` tool for lightweight workspace status checks

## Commands

```bash
npm install
npm run build
npm run dev
```

## Notes

This server is intentionally minimal and designed to be extended with workspace-specific tools.
